# Support

If you have any questions about using this course material,
please try these resources.

* Ask a question at the [CSDMS Help Desk](https://csdms.github.io/help-desk/)
* Sign up for a one-on-one meeting with a CSDMS research software engineer at [CSDMS Office Hours](https://csdms.colorado.edu/wiki/OfficeHours)

If you find technical problems in this repository,
please see the [Contributing](CONTRIBUTING.md) guidelines for reporting issues and contributing code.
